# Session 1 - Divide and Conquer

## Definition

Divide and Conquer is an algorithmic technique in which a large problem is divided into smaller subproblems. The smaller problems are solved separately and their solutions are combined to obtain the final solution.

Examples of Divide and Conquer algorithms are:

- Merge Sort
- Quick Sort

## Aim

To implement Divide and Conquer algorithms, specifically Merge Sort and Quick Sort, and analyze their time complexities.

## Algorithms

### Merge Sort

1. Read the array.
2. Divide the array into two halves.
3. Recursively sort both halves.
4. Merge the two sorted halves.
5. Display the sorted array.

## Time Complexity

Best Case: O(n log n)

Average Case: O(n log n)

Worst Case: O(n log n)

## Analysis

Merge Sort divides the array into smaller parts and then merges the sorted parts. It has O(n log n) time complexity.

sorting. Merge Sort successfully sort the given input array.
